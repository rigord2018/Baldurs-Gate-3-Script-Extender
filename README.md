## 🛠️ Troubleshooting & Common Fixes

**Issue: The game won't start after installing.**  
*Fix:* Make sure you placed `DWrite.dll` and the `Bin` folder in the correct game directory. Check that your game is fully updated to Patch 8. If the issue continues, remove the files and try again.

**Issue: The script extender isn't loading.**  
*Fix:* Right-click on `DWrite.dll` → Properties → check "Unblock" if the option appears. Then verify your antivirus didn't quarantine it.

**Issue: Console doesn't open.**  
*Fix:* Some keyboards use a different key. Try pressing the **backquote** or **F10** key. Also, restart the game after verifying the installation.

**Issue: Mods don't appear in-game.**  
*Fix:* You need a mod manager like BG3 Mod Manager (also available on GitHub). Install that, then enable your mods there.
